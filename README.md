# 할일요정 (task-reminder)

기존 NFCF_CRM과 **별개**로 쓰는 독립 앱입니다. 새 Supabase 프로젝트 + 텔레그램 봇이 필요합니다.
이 폴더만 새 저장소로 옮겨도 동작합니다.

## 설정 순서
1. **Supabase 새 프로젝트** 생성 → SQL Editor에서 `supabase/tasks.sql` 실행
   → 맨 위 주석의 `team_members` insert 를 실제 이메일/이름으로 실행 (본인 + 담당자)
2. **텔레그램 봇 생성**: 텔레그램에서 `@BotFather` → `/newbot` → 토큰과 사용자명 확보
3. **Edge Function 배포** (`supabase/functions/task-notify`, **JWT 검증 끄기**: `--no-verify-jwt`)
   시크릿 설정: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`(임의 문자열), `CRON_SECRET`(임의 문자열)
4. **웹훅 등록** (브라우저/터미널 1회):
   `https://api.telegram.org/bot<토큰>/setWebhook?url=https://<프로젝트>.supabase.co/functions/v1/task-notify&secret_token=<TELEGRAM_WEBHOOK_SECRET>`
5. **정기 알림**: `tasks.sql` 하단 pg_cron 주석을 `<CRON_SECRET>` 채워서 실행 (평일 08:30·15:30)
6. `index.html` 상단의 `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `BOT_USERNAME` 교체 후 호스팅(GitHub Pages 등)
7. Supabase Auth > URL Configuration 에 호스팅 주소를 Site URL/Redirect 로 추가
8. 각자 페이지에서 **텔레그램 연결하기** 1회 클릭

## 동작
- 등록 → 담당자에게 즉시 텔레그램 알림
- 미완료 → 평일 하루 2번 담당자별 요약 독촉 (기한초과 🔴 / 오늘마감 🟠 표시)
- 완료 체크 → 등록자와 다른 담당자에게 완료 알림, 전원 완료 시 🎉 알림

## 시세 / 경제뉴스 (PC 넓은 화면 오른쪽 열)
- `supabase/functions/info-feed` 배포 (`--no-verify-jwt`). 시크릿 불필요.
- 뉴스: 연합뉴스·한국경제·매일경제 경제 RSS (5분 캐시), 시세: Yahoo Finance 차트 API (1분 캐시)
- 화면 폭 1500px 이상에서만 표시됩니다.
- `task-notify` 도 페이지에서 호출하므로 CORS 헤더가 필요합니다 (이미 포함).

## 여신 / 수신 구분과 권한
- 상단 `[여신업무] [수신/기타]` 버튼으로 구분별 대시보드를 전환합니다. 각 대시보드는 **내 업무가 위**, 다른 담당자 업무는 **참고**로 아래에 나옵니다.
- 담당자마다 여신 / 수신·기타 / 관리자 권한을 줍니다. 권한이 없는 구분은 **보기 전용**입니다 (DB 규칙으로 막음).
- 관리자는 로그아웃 옆 `⚙ 관리자`에서 담당자 등록(계정+비밀번호), 권한 변경, 비밀번호 재설정, 삭제를 합니다.
- `supabase/functions/admin-users` 배포 필요 (`--no-verify-jwt`, 시크릿 불필요).

## 개인업무 · 고정업무
- 상단 `🔒 개인업무` 탭은 **본인만** 볼 수 있고 알림도 본인에게만 갑니다 (관리자도 다른 사람 것은 못 봅니다).
- `할 일`: 한 줄로 바로 추가, 기한을 넣으면 알림. 기한이 지나도 완료할 때까지 계속 알림.
- `🔁 고정업무`: 평일 매일 / 매주 / 매월(일자·말일) / 분기 / 반기 / 매년. 주말이면 금요일로 앞당기기·월요일로 미루기, N일 전부터 알림.
  날짜가 다가오면(21일 이내) 할 일이 자동으로 생기고, 완료하지 않으면 밀린 업무로 남아 계속 알립니다. 공휴일은 반영하지 않습니다.
- 서버 정기 작업(`task-notify`)이 매일 다음 회차를 만들어 둡니다.

## 대출 미진행
- 대출 업무 상세에서 `⛔ 미진행 처리`: 어느 단계에서든 선택 가능, 사유 입력(선택), 중단된 단계가 기록됩니다.
- 미진행 업무는 기본 목록(미완료)과 정기 알림에서 빠지고, 상태 필터 `미진행`에서 볼 수 있습니다.
- `↩ 진행 재개`로 언제든 원래 단계로 되돌립니다. 처리·재개 모두 담당자 전원에게 알림이 갑니다.

## 감정평가
- 상단 `🏛 감정평가` 탭. 권한은 관리자 화면의 `감정평가` 체크(관리자는 항상 가능). 권한이 없으면 보기만 가능합니다.
- 의뢰 등록: 본점/지점/통합(필수), 채무자, 의뢰자(로그인한 사람 자동), 물건 N개(구분 토지·건물·집합건물, 소재지, 지목, 면적), 의뢰할 평가기관, 알림 받을 사람.
- 소재지는 브이월드 지번 검색 결과에서 고른 주소만 입력됩니다(직접 입력 불가). 지목·면적은 자동조회를 시도하고, 안 되면 직접 입력합니다.
- 상세 화면의 가격표에서 기관별로 물건별 가격(원 단위)을 입력·저장하면 합계가 계산됩니다. 채택은 선택 사항입니다(채택 없이 가격만 조회 가능).
- 평가기관 목록은 관리자 화면에서 추가·숨김·삭제합니다.
- **지도(기록 찾기)**: 감정평가 탭을 열면 지도가 먼저 뜹니다. 지번을 검색하면 같은 필지·반경 내 기존 기록(보관 포함)을 보여주고, 기록이 없으면 `이 주소로 감정평가 의뢰`로 바로 등록합니다. 지도·라이브러리(Leaflet, markercluster, html2canvas)는 `vendor/`에 포함되어 있고, 지도는 브이월드 타일(인증키·도메인 등록 필요)을 씁니다.

## 주요일정
- 여신·수신/기타 화면 맨 위에 `📅 주요일정` (이번 주 일요일부터 14일, 일~토 × 2주). 관리자만 `＋ 일정 추가`·수정·삭제하고, 팀원은 보기만 합니다. 휴대폰에서는 일정이 있는 날만 목록으로 보입니다.

## 업무카드 댓글

여신·수신/기타 업무 상세창 아래쪽에 댓글을 남길 수 있습니다. 목록 카드에는 `💬 개수`가 표시됩니다.
- 작성: 업무 작성자 · 담당자 · 해당 구분 권한자 (그 외 팀원은 보기만) / 삭제: 본인 또는 관리자
- Enter 전송, Shift+Enter 줄바꿈
- 텔레그램: 댓글을 쓰면 작성자 본인을 뺀 업무 작성자·담당자에게 `💬` 알림 (Edge Function `task-notify` 의 `comment` 이벤트)
- DB: `supabase/tasks.sql` 의 `work_task_comments` 부분 참고

## 채권관리

상단 메뉴 **🛠 사후관리** — **연체채권관리**(연체 채무자별 관리) 화면입니다. **팀원 누구나 보기는 가능**하고(보기 전용 표시, 등록·수정·종결·삭제·CSV·조사일 입력 등은 숨김), 관리자가 프로필 > ⚙ 관리자 화면에서 팀원별 **사후관리** 권한을 체크하면(관리자는 항상 가능) 등록·수정까지 할 수 있습니다. DB도 조회는 팀원 전체, 쓰기는 권한자만 허용합니다.
- 채무자, 본점/지점, **내부연체기준일**(필수 아님 — 특수채권·연체예정채권은 비워두면 `연체일 미입력`으로 관리, 입력하면 오늘 − 기준일로 연체일수 자동 계산, 30일↑ 주황 · 90일↑ 빨강), **기한이익상실일**(미래 날짜를 넣으면 상실 예정일로 `예정 D-n` 표시, 지나면 `상실 n일 경과`, 비우면 미정), 연체 원금, 담당자, 메모. 목록 정렬에 `기한이익상실 임박순`, 상단 요약에 `기한이익상실 예정 N건(30일 내)`. 사후관리기록부 보고서에도 두 날짜가 모두 출력됨.
- **자산건전성**(정상·요주의·고정·회수의문·추정손실, 건전성별 색 칩, 목록 필터), **고정이하분류일**(기한이익상실일과 같은 예정일 방식: 미래면 `예정 D-n`, 지나면 `분류 n일 경과`, 정렬 `고정이하분류 임박순`, 요약 `고정이하 분류 예정 N건`), **관리일자·관리내역**(채권별 1건, 목록·상세·보고서에 표시). 보고서 요약표에는 `자산건전성(고정이하분류일)`·`관리일자·관리내역` 열이 추가됨.
- **연락·방문 이력**: 전화/문자/방문/면담/우편/기타 + 날짜 + 내용 (최신순), 이력을 남기면서 다음 조치일도 함께 지정 가능
- **다음 조치 예정일·내용**: 지연/오늘/D-day 표시, 목록은 조치 임박순(또는 연체일수순) 정렬, 메뉴 배지 = 오늘·지연 조치 건수
- 진행중/종결 구분(종결 시 종결 탭으로 이동, 되돌리기 가능). 텔레그램 알림은 없음(화면만).
- DB: `supabase/tasks.sql` 의 `debt_cases`, `debt_logs`, `has_debt()` 참고. 코드: `debt.js`

## 조합일정 / 개인일정

- **📅 조합일정** (여신·수신/기타 화면 맨 위): 관리자만 등록·수정·삭제, 팀원은 보기만. 종류: 조합행사/휴가/출장/외부행사/공휴일/기타. 텔레그램 일정 안내에는 공휴일을 뺀 조합일정이 나갑니다.
- **🗓 개인일정** (개인업무 화면 맨 위): 본인만 보고 본인만 등록·수정·삭제. 종류: 개인/약속/휴가/출장/기타. 조합 달력의 공휴일은 읽기 전용으로 같이 표시됩니다. 텔레그램 일정 안내(평일 아침 = 오늘, 오후 = 내일, 금요일 오후 = 토·일·월)에 **본인 개인일정만 본인에게** `🗓 내 일정`으로 붙습니다.
- 두 달력은 `calendar.js` 의 같은 코드(`makeCal`)로 만들어집니다.

## 우측 열 (넓은 화면 1500px 이상)

시세정보 · **💬 최근 댓글**(수신/기타·여신·감정평가 화면에서만, 각 화면의 댓글만 최신 5건 — 수신 화면은 수신 업무, 여신 화면은 여신 업무, 감정평가 화면은 감정평가 의견. 누르면 그 업무/건의 상세가 열림) · 경제뉴스(6건, 높이 제한).

## 감정평가 담당자 의견(댓글)

감정평가 상세 창의 가격 표(기관별 저장 버튼) 바로 아래에 **💬 담당자 의견 · 대출가능액** 입력창이 있습니다. 감정평가 내역으로 책정한 대출가능액 등을 남기면 시간순으로 쌓이고, 목록 카드에 `💬 개수`가 표시됩니다. 작성은 감정평가 권한자, 삭제는 본인 또는 관리자. 해당 건의 "알림 받는 사람"(작성자 제외)에게 텔레그램 `💬` 알림이 갑니다.

## 📊 현황판 (기본 화면)

상단 메뉴 맨 앞의 **현황판**이 기본 화면입니다 (열 때마다 현황판으로 시작, 주소 끝에 `#credit` 등을 붙이면 그 화면으로 바로 열림). 조합일정은 이 화면에만 있고 수신/기타·여신 화면에서는 뺐습니다.
- **여수신 현황**: 핵심 지표 카드(수신·여신 합산 잔액/목표/달성률/전 영업일 대비/전년말 대비 + 본점·지점 각각의 목표 대비 달성 막대, 연체율 목표 대비), 추이 그래프(PC는 카드 아래 수신·여신·연체율 3개 나란히, 폰은 탭 전환; 세로 범위는 실제 값 기준, 목표는 제목 옆 표시·근처일 때만 목표선), 보고용 상세표(접이식), 전년말 각주. ◀ ▶ 로 이전 영업일 기록을 볼 수 있음.
- **입력**: 관리자만. `＋ 실적 입력`(기준일 기본값 = 직전 영업일 — 주말과 달력의 공휴일 제외, 본점·지점 수신/여신 잔액(억원, 정수) + 합산 연체율), `⚙ 목표·전년말`(연 1회: 연 목표와 전년말 기준값). 같은 날짜는 덮어쓰기.
- **알림**: 평일 정기 알림(08:30·15:30) 때 직전 영업일 실적이 없으면 관리자에게만 `📊 [실적] 전 영업일 … 입력되지 않았어요` 텔레그램 (실적 기능을 쓰기 시작한 뒤부터).
- DB: `perf_daily`, `perf_year` (supabase/tasks.sql). 코드: `perf.js`

## ✅ 완료내역 (수신/기타·여신)

업무 목록 위쪽의 `진행중 | ✅ 완료내역` 전환 버튼으로 완료된 업무를 따로 봅니다(감정평가의 보관함처럼). 완료 + 미진행 업무가 **최근 완료순**으로 월별(`2026년 10월`)로 묶여 나오고, 완료일(일반업무 = 담당자 모두 완료한 날, 대출 = 마지막 단계 완료일, 미진행 = 처리일)이 표시됩니다. 대출진행/일반업무·본점/지점·내 업무만·검색 필터를 그대로 쓸 수 있고, 100건 넘으면 `더 보기`.

## 📄 대출 미진행 서류 보관 표지

수신/기타·여신의 **대출진행 업무 중 미진행 처리한 건**의 상세 창에 `📄 커버페이지 출력` 버튼이 생깁니다(`✅ 완료내역`에서 미진행 건을 눌러도 됨). 개인정보 동의서·대출신청서 스캔본을 웹에 올리지 않고 자체 보관할 때 맨 앞에 끼우는 A4 한 장 표지입니다.

## 🏭 정책자금실태조사 (사후관리 안의 두 번째 탭)

- **기준은 대출건**: 완료·대출잔액은 대출건 하나에 한 번. 한 대출건의 **현장(사업장)은 여러 곳** 가능 — 수정 화면의 `＋ 현장 추가`, CSV는 같은 고객번호·계좌번호로 줄을 늘려 소재지만 다르게 적기(이미 있는 대출건은 현장 목록이 파일 기준으로 교체). 실태조사일은 현장을 모두 다녀온 뒤 대출건에 한 번만 입력.
- **📥 CSV 올리기**: 양식 내려받기 → 엑셀에서 작성 → CSV 저장 후 업로드(한글 엑셀·UTF-8 모두). 고객번호+계좌번호가 같으면 덮어쓰기(비운 조사일·담당자는 기존 값 유지). 담당자는 이름(등록된 팀원이면 연결).

- **📍 현장 묶음 추천**: 목록 화면에서 고른 사업구분·담당자·검색 조건에 맞는 미완료 건만 대상으로 하고, 지도는 일반/항공 중 골라 화면·인쇄에 같이 적용. 묶음별 색깔 번호 마커와 방문 순서 점선을 지도(브이월드)로 보여주고, 미완료 건의 사업장 주소를 브이월드로 좌표 변환(📌 위치 확인) → 묶음 크기(2~20km)·최대 건수를 정해 가까운 곳끼리 자동 묶음. 방문 순서 제안, 묶음별/전체 인쇄(묶음 지도·전체 지도 그림 포함), 같이 조사한 묶음은 조사일 한 번에 입력. 좌표를 못 찾은 주소는 읍·면·동 기준으로 따로 묶음. (생성형 AI가 아니라 거리 계산 알고리즘)
- 묶음 추천은 현장 하나하나를 점으로 묶어서, 한 대출건의 현장이 서로 다른 묶음에 걸칠 수 있음(`현장 2/3` 표시, 잔액은 묶음 안에서 한 번만 합산). 묶음 단위 일괄 완료는 현장이 전부 그 묶음 안에 있는 대출건만 처리.
- DB: `survey_cases`, `survey_sites` (supabase/tasks.sql). 코드: `survey.js`.

## 🧮 임대사업자 RTI 계산 (감정평가 화면의 두 번째 탭)
`🏛 감정평가` / `🧮 임대사업자 RTI 계산` 탭. 조회는 팀원 전체, 저장·수정은 감정평가 권한자, 기준값(⚙) 수정은 관리자.
- **임대소득(연간)** = 월세×12 + 전세보증금×기준금리 + 추정-월세×12×추정비율 + 추정-전세×기준금리×추정비율 (기준금리 = 예금은행 수신금리, 추정비율 기본 70%)
- **이자비용(연간)** = Σ 원금 × (금리 + Stress). Stress(스트레스 금리)는 **변동금리 대출에만** 가산하고 3년 이상 고정금리는 제외(행마다 금리유형 선택). 기존·신규 대출은 행을 추가해 여러 건 입력. 기존대출의 실제 금리를 모르면 금리를 비워두면 참고금리(예금은행 대출금리·잔액기준 중소기업대출 가중평균금리)가 적용됨. Stress 값은 ⚙ 기준값에서 입력하며, `Stress 계산` 도우미(최근 3년 최고 금리 − 최근 월 금리, 1%p 미만이면 1%p)를 쓸 수 있음.
- **RTI** = 임대소득 ÷ 이자비용(소수 둘째 자리 반올림). 판정: 비주택 원칙 1.50배↑ / 여신위원회 승인 시 1.20배↑, 주택 1.25배↑ / 1.00배↑ (미달·원칙·승인 시 충족). 예외: 신규대출 합계 1억원 이하(소액), 불가피한 채무 인수(체크).
- 고객별로 저장해 목록에서 다시 열기, 보고서 인쇄(`🖨 인쇄`). 저장된 계산은 저장 당시의 기준금리·Stress를 그대로 유지(기준값을 바꿔도 안 바뀜).
- DB: `rti_calcs`, `rti_settings` (supabase/tasks.sql). 코드: `rti.js`.

## 💰 자금운영관리 (사후관리의 세 번째 탭, 사후관리 권한자·관리자만)
기존 엑셀 `자금운영현황`의 구성을 그대로 화면으로 옮겼고, **기준일자별로 저장**합니다(`fund_days`). 새 날짜는 `직전 기록 복사해서 시작` → 바뀐 금액만 고쳐 저장. 위쪽 `📋 전일자 불러오기(직전 저장일)` 버튼은 어느 날짜에서나 쓸 수 있고(지금 내용을 덮어쓰기 전 확인), 저장하기 전까지는 원래 기록이 그대로 남음.
1. **자금조달 및 운영** — 조달(중앙회일시자금·대외예치금·정기예탁금 1개월·사업미수금) / 운영(대출·민관협력과·법인자금지출) / 차액. 다른 항목에서 가져오는 **연동값**(중앙회일시자금←2번, 대출←6번, 법인자금지출←6번)은 자동, 엑셀처럼 비워 두던 행(대외예치금·정기예탁금)은 직접 입력하되 연동 가능한 값을 옆에 표시(`연동 n`을 누르면 적용). 행마다 `연동`↔직접 입력 전환.
2. **중앙회 자금현황** — 일시자금(금리) · 정기예탁금(1/3/6/12/24개월, 만기일·금리는 `2027-01-02~`, `2.83~2.93%` 같은 범위 글자도 가능) · 소계/합계 · 정기예탁금범위내대출.
3. **법인자금현황** — 기관별 계좌 잔액(내역·계좌·금액·적요), 기관 소계/합계, 민관협력과 지출 일정(일자·금액, 월별 합계 자동).
4. **대외예치금 현황** — 본점/지점별 계좌·금액·만기일·비고, 합계.
5. **대출 실행예정 현황** — 본점/지점, 성명·과목·금액·실행예정일(또는 `미정`)·비고, 구분별 건수·소계, 이번 달 예정/미정 합계, **예정일이 지난 행은 붉게** 표시.
6. **자금집행 예정내역** — 대출실행은 5번에서 기준일이 속한 달의 예정분(미정 제외)을 자동 합산(직접 입력으로 바꿀 수 있음) + 법인자금 항목들.
7. **기타사항** 메모.
- **중앙회 금리표**(7번 기타사항 아래): 기준일자 / 일시자금 / 정기예탁금 1·3·6·12·24·36개월 / 환담보예치금 / 상환준비금 금리를 기준일자(적용 시작일)별로 입력. 자금운영 기준일에는 그 이하의 가장 최근 금리표가 자동 적용되어 표시되고(과거 기준일은 그때의 금리표), 2번의 `금리표 적용` 버튼이 빈 금리 칸(일시자금·정기예탁금 기간별)을 채움. 인쇄에도 포함. DB: `fund_rates`.
- 위쪽에서 날짜 이동(◀ ▶ · 달력 · 최근 저장일 버튼), 아래 `일자별 요약`(조달·운영·차액·중앙회·법인자금·대출예정 추이)에서 날짜를 눌러 열기. `🖨 인쇄`는 엑셀과 같은 서식(A4 세로)의 보고서. 코드: `fund.js`.

### 현황판 · 규제유동성비율
수신·여신·연체율 카드 아래의 **규제유동성비율** 카드(관리자가 **`＋ 실적 입력`에서 수신·여신·연체율과 함께**(또는 카드의 `＋ 입력`으로 따로) 기준일·유동자산합계·유동부채합계를 **백만원** 단위로 입력). 비율 = 유동자산합계 ÷ 유동부채합계(소수 둘째 자리), **기준 100% 이상 유지** — 충족/미달과 기준 대비 %p, 막대(100% 눈금)와 최근 추이 선을 표시. 기준일은 다른 지표와 같은 전 영업일(◀▶로 이동)이며, 비교는 **전월말**·**전분기말** 값(그 날짜 이하의 가장 최근 입력)과의 %p 차이. 전월말·전분기말 값은 같은 입력창에서 그 날짜로 입력해 두면 비교에 쓰임(없으면 '입력 필요' 안내). DB: `perf_liq`.

수신·여신·연체율·규제유동성비율 **카드 4개와 추이 그래프 4개를 각각 한 줄(가로 4칸)**로 배치(폭 1100px 이하는 2×2, 모바일은 1열 + 추이 탭).
